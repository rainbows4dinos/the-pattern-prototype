# Centerpiece components

"One interactive focal object per screen" means those objects recur across
prototypes. This is where each lives as a standalone reference implementation. A
new prototype pulls the centerpiece it needs from here rather than rebuilding it.

Reference implementations are about interaction and structure, not final visual
style. They consume the neutral tokens like everything else and reskin when brand
lands.

Planned:
- `cycle-slider.html` — interactive date/moon/planet slider. Alternative to
  Lens's card stack. Open design item.
- `personality-wheel.html` — focal object for the You section.

Nothing here yet. The visual direction is unsettled, so these are held until
there is a real interaction to commit rather than a speculative one.
