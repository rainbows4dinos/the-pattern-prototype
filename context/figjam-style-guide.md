# FigJam style guide

Status: open item. Not yet written.

Purpose: a style guide Claude can follow across sessions when building or editing
FigJam boards for The Pattern, so boards stay consistent without re-deriving
conventions each time.

To capture when written:
- Section header conventions and hierarchy.
- Text node sizing and weight per level (title, body, annotation).
- Bullet formatting. Larry's standing instruction is a soft line break after each
  bullet to fake extra spacing (see figma-technical-notes.md).
- Color use for annotations, callouts, and status.
- Layout and spacing grid.
- Naming conventions for nodes and sections.

The technical "how" lives in figma-technical-notes.md. This file is the visual
and editorial "what."
